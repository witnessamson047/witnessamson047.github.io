To use your own photos: drop a JPG/PNG into this folder and change the matching
src in the HTML. Card images are 16:9 (21:9 for the featured card); add the
"photo" class to a card image so it fills the frame with object-fit: cover
instead of being padded. Keep the subject near the centre.

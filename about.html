About me.

Hello! I'm Witness, a self-taught developer from Tanzania. I build modern, fast and secure websites that help small businesses grow online.

Hire me → See my projects

I learned to code by building real things, not just tutorials. The biggest project I have built so far is Oweru Tech Solutions, a complete platform that checks a website's health, finds its weaknesses, and politely explains to the owner what should be improved.

Along the way I learned how websites actually work: how pages load, how emails should look, how payments flow, and how to make boring technical data look beautiful and easy to read.

I enjoy the path where web development meets cybersecurity: knowing how a site is built helps me understand how it can be tested and protected.

When I am not coding I am usually reading about how businesses use the internet in Tanzania. Every weak website I find is a problem waiting for a solution.

Featured project

Oweru Tech Solutions

A website health and security platform I have been building on my own: it looks at any website, runs 23 automated checks, and explains in plain language what is wrong and what to fix first.

  • Discovery and crawling. Finds real businesses from public map data, then walks through their pages.
  • Health scanning. Checks security, mobile friendliness, speed and trust, then gives each site a score.
  • Plain-language reports. Every failed check comes with a reason and a suggested fix, not just a red cross.
